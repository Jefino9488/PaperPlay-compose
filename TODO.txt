Marks: [x] done and builds, [~] half done, [ ] not done.

Speed and battery (12 Nov, big win on the phone)
[x] Library reloads are batched to about one every 2 seconds, one shared song list
[x] Fewer background workers (metadata 2, covers 1, lyrics 2), batched writes
[x] Full rescan of every chat resumes instead of restarting, runs in the foreground

[x] Keep-running service is off by default and stops when nothing is running
[x] Position updates no longer redraw the whole screen, scan progress split out
[x] Chats and channels page uses lazy lists, covers use a real cache and
    smaller thumbnails, theme and shapes are remembered
[x] Songs start faster: lookup runs next to queue setup, next and previous are

[x] Smaller release APK: 35 MB down to 15.7 MB
